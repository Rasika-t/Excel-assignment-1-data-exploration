# Excel Assignment 1: Data Exploration & Analysis

## 📌 Project Overview
This project is part of the AI-Driven Data Analytics coursework. It demonstrates foundational data exploration, logical conditions, conditional aggregation, and text manipulation techniques using Microsoft Excel.

---

## 🛠️ Tasks & Methodology

### 1. Basic Data Summarization & Statistics
* Applied statistical functions (`SUM`, `COUNTA`, `AVERAGE`, `MIN`, `MAX`) to analyze product pricing and dataset volume.

### 2. Logical Functions (`IF`)
* Created a calculated column (`Price Range`) using logical conditions to classify products:
  * `>= $500` $\rightarrow$ **High Price**
  * `< $500` $\rightarrow$ **Standard Price**

### 3. Conditional Aggregation (`SUMIF`, `COUNTIF`)
* Computed conditional metrics:
  * Total price of products within the **Electronics** category using `SUMIF`.
  * Total number of items priced under $100 using `COUNTIF`.

### 4. Text Processing & Transformation (`LEFT`, `RIGHT`, `MID`)
* Extracted structured components from the `Product ID` string:
  * **Day:** Extracted first 2 characters using `LEFT`.
  * **Country Code:** Extracted last 2 characters using `RIGHT`.
  * **Month:** Extracted characters 4 through 6 using `MID`.
